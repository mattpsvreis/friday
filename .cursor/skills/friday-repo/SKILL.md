# Friday repository

Friday (`package.json` name `Friday`) is a single-package Next.js app. `pnpm-workspace.yaml` holds pnpm settings only — not a multi-package workspace.

## Toolchain

- Package manager: **pnpm** only (`pnpm-lock.yaml`). Never npm, yarn, or bun.
- Node.js: **24** (`.nvmrc`). Keep `@types/node` current; do not downgrade Node to match types.
- App: `next@16.4.0`, React 19, App Router under `app/`. No `pages/`, no `src/`.
- TypeScript `strict: true`. Path alias `@/*` → repo root.
- Styles: Tailwind CSS 4 via CSS (`app/globals.css`). No `tailwind.config.js`.
- Data: Drizzle ORM + `postgres` driver. Schema in `db/schema.ts`.
- Charts: Recharts. Icons: Lucide (chrome only).

## Commands

| Task | Command |
| --- | --- |
| Install | `pnpm install` |
| Dev (app only) | `pnpm dev` |
| Boot DB + app | `scripts/dev.bat` / `scripts/dev.sh` |
| Build / start | `pnpm build` / `pnpm start` |
| Lint | `pnpm lint` |
| Schema push | `pnpm db:push` |
| Add dep | `pnpm add <name>` / `pnpm add -D <name>` |

Keep `pnpm-lock.yaml` in commits. Do not commit `node_modules`, `.next`, or `.env*`.

## Before editing Next.js code

This Next.js version differs from older releases. `AGENTS.md` is regenerated by `next dev` — leave the `nextjs-agent-rules` block intact.

1. If `node_modules/next` is missing, run `pnpm install`.
2. Read guides in `node_modules/next/dist/docs/` before changing routes, layouts, caching, or fonts.
3. Keep `next.config.ts`: `cacheComponents`, `partialPrefetching`, Turbopack `*.css` → `@tailwindcss/turbopack`.

## Where code goes

| Path | Role |
| --- | --- |
| `app/layout.tsx` | Root layout; Comfortaa + Source Serif 4; `CurrencyBackground` |
| `app/(app)/` | Auth-gated pages + `AuthGate` + `AppShell` |
| `app/unlock/` | Password setup / unlock |
| `app/api/` | Route handlers |
| `app/globals.css` | Tailwind entry, neon tokens, glass, scroll hide |
| `components/` | Shared UI |
| `lib/` | Domain, auth, hooks, UI class constants |
| `db/` | Drizzle client + schema |
| `public/brand/` | Logo assets |

## Tailwind

Utilities on `className`. Tokens in `app/globals.css` (`:root`, `@theme inline`). Dark-only — no light `prefers-color-scheme` branch. Do not add `tailwind.config.js`.
